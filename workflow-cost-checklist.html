1. Count outcomes, not only calls

  • Pick one customer-visible workflow.
  • Count successful completed runs separately.
  • Count failed, retried, abandoned, and human-rescued runs separately.
  • Calculate cost per successful workflow.

2. Tag the top 20 expensive runs

  • Model used per step.
  • Input and output token spend.
  • Tool calls, context size, and memory injected.
  • Whether the run reached a useful business outcome.

3. Check hard caps, not soft hopes

  • Set a per-workflow cost ceiling.
  • Set a per-user or per-team monthly ceiling.
  • Kill or downgrade retry-heavy runs automatically.
  • Separate staging, internal, and customer usage budgets.

4. Run the ugly-month scenario

  • Normal month.
  • 2x usage month.
  • Retry-heavy month.
  • One power user on a flat plan.
  • Kill or reprice any plan that goes negative there.
