1. Count completed work, not calls

  • Pick one workflow: sales research, support triage, HR screening, ops report.
  • Count successful completed runs.
  • Count failed, retried, abandoned, and human-rescued runs separately.
  • Calculate cost per successful workflow, not only cost per token.

2. Tag the top 20 expensive runs

  • Model used per step.
  • Input and output tokens per step.
  • Tool calls per run.
  • Context size and memory injected.
  • Whether the run changed a useful business state.

3. Look for the boring leaks

  • Retries after bad tool/API responses.
  • Full chat history passed into every call.
  • Large files parsed again instead of cached.
  • Frontier model used for extraction, routing, or formatting.
  • Agent loops that research before doing the actual task.

4. Add pricing guardrails

  • Set a per-workflow cost ceiling.
  • Set a per-user or per-team monthly cap.
  • Define overage before a power user appears.
  • Separate normal month, 2x volume month, and ugly retry-heavy month.
  • Kill or reprice any plan that goes negative in the ugly month.
